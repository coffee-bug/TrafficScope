# TrafficScope 主程序

这里是 TrafficScope 的主程序源码，C++17 配 Qt6 Widgets，编出来两个可执行文件。`TrafficScope.exe` 是桌面浮框本体，`TrafficScopeHost.exe` 是浏览器扩展用的 Native Messaging 宿主，不装扩展它就是个摆设，主程序照常工作。

依赖怎么装、怎么编译，都写在仓库根的 `README.md`。这一篇讲软件本身。

## 浮框

无边框置顶小窗，默认每秒刷一次上传与下载速率，间隔可以在 100 到 10000 ms 之间调。能拖着走，拖到屏幕边缘会吸附收起，位置和吸附边下次启动还在。

单击浮框展开实时榜，悬停不展开。榜分「上传 Top」和「下载 Top」两段，面板顶部显示今日累计下载与上传，每 10 秒查一次历史库。

检测到有程序全屏（游戏、放映）会自动取消置顶并隐藏，每 250 ms 判一次，退出全屏后按原状态恢复。托盘图标右键菜单和浮框右键共用一份，有查看详情、设置、退出；左键直接打开设置。浮框被全屏隐藏时，托盘是唯一的入口。

## 详情弹窗

从实时榜点「查看详情」进来，四个页签。

应用页有程序名称（含 exe 文件描述）、下载与上传速度、累计、连接数。每行可以「打开位置」，在资源管理器里定位到 exe；点进程行展开，列出这个进程名下的已建立连接（进程 ID、系统或第三方类别、速率、连接数）。结束进程支持单个 PID 和同名全部，都要二次确认。

域名页是域名、下载与上传速度、累计。

网站页按「这个请求来自哪个页面」聚合。装过扩展时优先用扩展回传的归属，它最准；没装也能出数据，走注册域名（eTLD+1），DNS CNAME 链上的 CDN 域名归到链头那个站。点网站行展开，看组成它的每个域名或裸 IP 各贡献了多少。名字后面带 `*` 表示这个网站里混着被多个站共用的 CDN，归属可能不准。

历史累计页按应用、域名、网站查历史。时间区间用双月日历弹层选，另有今天、最近3天、最近7天、最近30天、全部几个快捷项。显示区间累计与趋势柱状图，区间超过 2 天按天分桶；鼠标停在柱子上出该时段明细。搜索框筛名称时，表格、柱状图和区间总量一起变，占比列按筛出来的那部分重算。

弹窗顶部画最近 120 拍的上传下载曲线，纵轴随当前流量自适应，峰值速率跟在「上传总速度」旁边。

四个页签都能点表头排序、按名称搜索（多个词用空格分开，需要全部命中，Esc 清空），右上角可导出 CSV，带 BOM，Excel 双击不乱码。弹窗尺寸可调，改完记住。

## 设置

设置弹窗左侧导航五页，改完点「应用」生效。

显示页有窗口置顶、全屏时自动隐藏、自动贴边隐藏、开机自动启动、速率单位（字节 B/s 与比特 bps 两选一，字节按 1024 进制，比特按 1000 进制）、面板顶部是否显示峰值、界面字体（列系统字体，可输入过滤）、刷新频率。

统计页有不再统计未知流量（旁边 ⓘ 说明这类流量怎么来的）、启用浏览器扩展归属（开关加一行状态和「查看安装步骤」按钮）、重置统计（只清本次运行的内存累计，不动历史库）。

历史记录页有记录粒度（小时或天）、应用与域名保留天数（7 天到永久，默认 90 天）、清空历史记录。

网卡页可以自动选择（跟随系统默认路由）或手动指定，下面实时显示当前网卡和抓包、计入计数。这个选择不保存，下次启动回到自动。

关于页是版本号、作者、数据目录完整路径和「打开数据目录」。

「重置统计」和「清空历史记录」点了立即执行，撤不回来；其余改动都要点「应用」，点取消或直接关窗会丢掉本次改动。

## 归因

### 应用

抓包只能看到四元组，看不到包属于哪个进程。按优先级试四层。

1. ETW 实时映射。订阅内核 `Microsoft-Windows-TCPIP` provider，TCP 连接建立与断开事件直接带 PID，UDP 收发事件带 PID 和字节数。没有采样间隙，短命连接也抓得到。
2. 连接表快照。每 300 ms 用 `GetExtendedTcpTable` 和 `GetExtendedUdpTable` 取一次，按精确四元组匹配。
3. 通配兜底。绑在 `0.0.0.0` 或 `::` 的 socket（UDP 出站常见），按本机端口匹配。
4. 端口短期记忆。记住本机地址加端口对应的 PID，TCP 记 120 秒，UDP 记 15 秒。

四层都没命中的算未知流量。它是个兜底桶，不对应任何进程。

### 域名

- 嗅探 UDP 53 应答，建 IP 到域名的映射，按 TTL 过期
- 解析 TCP 443 的 ClientHello，从 SNI 拿域名，补 DNS 看不见的场景

两条路都拿不到就显示裸 IP。

### 网站

三级回退，顺序是扩展回传、DNS CNAME 链、域名自己的注册域名。扩展那条最准，它站在浏览器里，知道请求由哪个页面发出，同一页加载的 CDN 域名和 IP 字面量资源都能算到这个站上。没有扩展时靠后两级推，粒度粗一点，但不会把不相干的域名硬凑进一行。

拿不到线索的流量不进网站维度，所以网站总量通常小于域名总量。

## 架构

```
抓包线程  PacketSource (系统原生 NDIS ETW 实时通道)
   └─ PacketParser      以太网 / VLAN + IPv4 / IPv6 + TCP / UDP 解析，判定方向
        ├─ TrafficStore     按应用 / 域名 / 网站累计，按刷新节拍算速率，Top-N
        ├─ DnsSniffer       UDP 53 应答 → IP 到域名（TTL 过期），留存 CNAME 链
        ├─ TlsSniParser     TCP 443 ClientHello SNI → IP 到域名
        ├─ SiteName         注册域名计算（eTLD+1，内置多级后缀表）
        └─ SiteResolver     域名 / IP → 网站
归因
   EtwSniffer       内核 TCPIP 事件 → 四元组 → PID
   ProcTraffic      300ms 连接表快照 + 端口短期记忆
持久化
   StatsRecorder    每 60s 落盘，时间桶由记录粒度决定
   StatsDb          SQLite（%LOCALAPPDATA%\TrafficScope\data\traffic.db）
全屏检测
   FullScreenDetect 前台窗口矩形 + SHQueryUserNotificationState，250ms 一次
入口
   QSystemTrayIcon  托盘，右键菜单与浮框共用 FloatWidget::fillMenu
   AutoStart        开机自启 = 计划任务 TrafficScope（ONLOGON + 最高权限）
   SingleInstance   单实例守卫，用 Win32 命名管道
UI 线程  FloatWidget（按刷新节拍刷浮框，单击展开 TopPanel）
   ├─ DetailDialog   应用 / 域名 / 网站 / 历史累计 四页签
   ├─ SettingsDialog 显示 / 统计 / 历史记录 / 网卡 / 关于 五页
   └─ Charts.h       SpeedGraph 与 HistoryChart，纯自绘，颜色读 ts::theme()
```

## 数据落盘

用户数据都在 `%LOCALAPPDATA%\TrafficScope`，不往安装目录写。路径在设置的关于页能看到，也能一键打开。

| 文件 | 内容 |
|---|---|
| `data\traffic.db` | 历史统计，SQLite WAL 模式，每 60 秒 UPSERT 累加。小时粒度写 `hourly_app` / `hourly_domain` / `hourly_site`，天粒度另写 `bucket_app` / `bucket_domain` / `bucket_site`，多存一个 `end_ts` 记这行覆盖到哪。两种行统计时合并求和 |
| `settings.ini` | 浮框位置与吸附边、刷新频率、字体、速率单位与峰值开关、全屏与贴边开关、保留天数、记录粒度、是否统计未知流量、扩展归属开关、弹窗尺寸 |
| `data\etw_probe.log` | ETW 诊断日志，默认不生成 |

注册表只在主程序运行期间写 Chrome 与 Edge 的 Native Messaging 登记项，退出就删，崩溃残留下次启动清掉。关掉「启用浏览器扩展归属」就完全不写。除这个之外不碰注册表。

## 已知限制

- DoH 与 DoT 的加密 DNS 嗅探不到，这类流量靠 SNI 兜底
- QUIC（HTTP/3）的握手加密在 CRYPTO 帧里，当前不解析 SNI，这类流量显示成 IP
- 程序启动前就存在的存量连接、完整落在两次快照之间的极短命连接，可能归因失败。用户态方案的固有上限，ETW 已经覆盖了其中大部分，剩下的通常在几百 KB 量级
- 字节按网线上的原始包长统计，含链路层开销，跟路由器口径可能有 ±2% 的差
- 抓包基于 Windows 10/11 原生 NDIS ETW 提供程序，零第三方驱动依赖；低流量待机时受系统 FlushTimer 兜底影响可能存在约 1 秒的投递延迟，有流量时立即实时投递（缓冲区平均延迟约 98ms）
- 网站维度的历史按当时解析出的归属落库。切换记录粒度不重写已有数据，同一时段可能两种粒度并存，统计时合并求和
- 开机自启依赖名为 `TrafficScope` 的计划任务，卸载前先在设置里取消勾选，否则任务会残留并指向已删掉的 exe。程序路径变了重新勾选一次就能覆盖
- 全屏判据是「前台窗口盖满所在显示器」加「系统报告正在跑全屏 D3D 程序」，最大化窗口并且任务栏自动隐藏时也会被判成全屏。多屏时任一屏全屏即整体隐藏。本程序自己的弹窗不计入
- 网卡选择不保存，每次启动回到跟随系统默认路由
- 界面只有一套深色配色，没有明暗切换入口，换配色要改 `ui/UiTheme.h` 的 `darkTheme()`
- 详情弹窗里的累计下载与上传是本次运行的内存累计，重启清零，跟历史累计页读库的数字不同源
- 扩展只覆盖浏览器流量，微信、云盘、游戏、系统更新没有网站归属，只在域名维度里出现
